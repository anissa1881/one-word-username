# One Word, One Username

A tiny entry for make.fun's "One Word, One Username, One Reward" bounty: the program writes the entrant's own make.fun username — one word, nothing else — to `entry.txt`.

[![make.fun](https://make.fun/badge/u-rusdyxbt-one-word-one-username-one-reward-1a191fae.svg)](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae)
[![rank](https://make.fun/badge/u-rusdyxbt-one-word-one-username-one-reward-1a191fae/anissa1881/one-word-username/rank.svg)](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae)
[![reward](https://make.fun/badge/u-rusdyxbt-one-word-one-username-one-reward-1a191fae/anissa1881/one-word-username/reward.svg)](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae)

Run it with Node 22+ (stdlib only, nothing to install):

```sh
node main.ts
```

It writes `anissa1881` to `output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
